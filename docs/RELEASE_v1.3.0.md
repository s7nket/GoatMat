# GoatMat v1.3.0

**15 August 2026 · Android APK**

---

## What's New

- 🗺️ **Area Calculator** — Enter room dimensions or total sq ft, pick a mat, instantly get mats needed, cost, and stock coverage
- 📐 **Mat Dimensions** — Products now store Width & Length (ft) used by the calculator
- 🎨 **Colour per Bill Line** — Buy/sell multiple colours of the same mat on one card, with per-colour stock checks
- 🖨️ **PDF & Bill Improvements** — Colour, warranty, and payment terms printed on customer bills
- 💳 **Advance Payments** — Track customer advances and settle bills against them
- 🛡️ **Stock Guards** — Oversell protection on every sale, online and offline

---

## Install
Download the APK → allow unknown sources → install → sign in.

> **DB migration:** Run `supabase/014_mat_size.sql` in Supabase SQL Editor before using the Area tab.
